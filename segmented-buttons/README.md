# Segmented Buttons

A compact Bootstrap-friendly styling pattern for grouping actions into segmented controls.

This module is useful when a single toolbar or button cluster needs to present several related actions as one cohesive control while preserving the overall Bootstrap visual language.

## What it does

- supports horizontal and vertical segmented layouts
- works with Bootstrap button classes and icons
- helps create compact menu-like action groups
- provides a clean demo for common UI patterns

## Files

- `segmented-buttons.css` — main styling for the segmented button pattern
- `segmented-buttons-example.html` — complete sample page with live usage examples

## Quick usage

```html
<button type="button" class="btn btn-success btn-segmented">
  <span class="bg-darker"><i class="bi bi-check"></i></span>
  <span>Success</span>
</button>
```

For a vertical layout, add the `btn-segmented-vertical` class to the same structure.

## Example page

Open `segmented-buttons-example.html` in a browser to preview the available styles and configurations.
