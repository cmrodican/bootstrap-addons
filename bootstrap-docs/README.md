# Bootstrap Docs

This folder contains documentation-oriented CSS assets inspired by bootstrap's design system and reference styles.

## Purpose

The stylesheet in this folder is intended for examples, demos, and documentation pages that need a Bootstrap-like presentation without introducing a full package installation.

## Files

- `bootstrap-docs.css` — documentation and layout styling helpers

## Usage

Include the stylesheet in a page alongside Bootstrap:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" />
<link rel="stylesheet" href="bootstrap-docs.css" />
```

This is most useful for sample pages, documentation sections, and self-contained UI demos.
