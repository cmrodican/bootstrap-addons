# Bootstrap Addons

A curated collection of Bootstrap enhancements, UI controls, and interaction patterns for static websites.

This repository groups small, independent modules that can be dropped into Bootstrap-based projects without a build process or framework setup. Each component is designed to be easy to copy, adapt, and integrate into custom dashboards, admin panels, kiosks, and static marketing sites.

This project is not affiliated with Bootstrap. For the official project, see [bootstrap](https://github.com/twbs/bootstrap) and [getbootstrap.com](https://getbootstrap.com/).

## Project website

The static project website is ready to publish with GitHub Pages at [cmrodican.github.io/bootstrap-addons](https://cmrodican.github.io/bootstrap-addons/). It includes an overview and a dedicated page for each add-on.

To publish or update it, configure GitHub Pages in the repository settings to deploy from the root of the `main` branch. The site uses plain HTML and CSS and does not require a build step.

## Featured modules

### App Menu
The [appmenu](./appmenu) module adds a desktop-style application menu bar with hover navigation, modal-driven actions, and JavaScript-based menu configuration.

### CSS Grid
The [css-grid](./css-grid) module introduces utility classes that extend Bootstrap layouts with CSS Grid patterns, including responsive column spans and semantic page layouts.

### Enhanced Bootstrap Table
The [enhanced-bootstrap-table](./enhanced-bootstrap-table) module turns a regular Bootstrap table into a richer data grid with sorting, filters, resizing, and JSON population support.

### TV Navigation Framework
The [tv-navigation-framework](./tv-navigation-framework) module provides keyboard navigation patterns for TVs, remote controls, and kiosk interfaces. It is designed to make static Bootstrap pages easier to navigate without a mouse.

### Segmented Buttons
The [segmented-buttons](./segmented-buttons) module adds horizontally or vertically segmented button layouts for compact action groups and menu-like controls.

### Bootstrap Docs CSS
The [bootstrap-docs](./bootstrap-docs) folder contains Bootstrap-inspired documentation styles used for examples and theme assets across the repository.

## Getting started

1. Browse the module folders above to choose the component you need.
2. Open the module's local README, demo HTML file, or example page.
3. Copy the relevant CSS or JavaScript file into your project and include it alongside Bootstrap.
4. Customize the component by editing its configuration or example markup.
