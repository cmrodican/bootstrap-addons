ABOUT THIS PROJECT

Small, practical pieces.
Built to be customized.

Bootstrap Addons is a collection of independent experiments and enhancements for Bootstrap-based websites. Take only what fits, read the source, and make it your own.

This project is community-maintained and is not affiliated with the Bootstrap team.
