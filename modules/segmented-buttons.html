Segmented Buttons

Group a set of related actions into a single, polished control with horizontal and vertical segmented button styles.

Open the example ↗Browse source ↗

Preview

The CSS styles the direct children as connected segments, preserving the outer button shape and adding separators.

DayWeekMonth

Quick start

Include Bootstrap and the add-on stylesheet, then place segment elements inside a Bootstrap button.

<link rel="stylesheet" href="segmented-buttons/segmented-buttons.css">

<button type="button" class="btn btn-primary btn-segmented">
  <span>Day</span>
  <span>Week</span>
  <span>Month</span>
</button>

For a vertical arrangement, add btn-segmented-vertical to the button. Segments may contain text, icons, or other inline content.
