App Menu

Bring the familiar File / Edit / View / Help pattern to Bootstrap-powered web applications with a menu configured in JavaScript.

Open the demo ↗Browse source ↗

What it does

The app menu generates a desktop-style menu bar from a JavaScript configuration. It supports switching between open top-level menus on hover, actions routed through handlers, and Bootstrap modal integration.

  • Define menu labels and items in one place.
  • Connect commands to your application's own action functions.
  • Use included examples for clipboard, find, and segmented-button patterns.

Quick start

Start from the included demo page and its dependencies. The example uses Bootstrap 5.3 and Bootstrap Icons.

<!-- Include Bootstrap 5.3 and Bootstrap Icons -->
<link rel="stylesheet" href="appmenu/css/style.css">
<div id="navbar-container"></div>
<div id="modal-container"></div>
<script src="js/script.js"></script>
The supplied example page includes the required containers and Bootstrap bundle. Use it as the integration reference.

Project files

  • index.html — working example page
  • js/script.js — menu setup, configuration, and actions
  • css/style.css — menu presentation
