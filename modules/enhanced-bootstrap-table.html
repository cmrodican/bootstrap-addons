Enhanced Bootstrap Table

Add useful data-table interactions to existing Bootstrap tables: filter values, sort by data type, and resize columns.

Read the full guide ↗Browse source ↗

Features

  • Column filters with searchable checkbox options.
  • Data-aware sorting for text, numbers, currency, dates, times, and more.
  • Resizable columns and optional JSON-based table population.
  • Uses Bootstrap 5.3 styling and Bootstrap Icons.

Quick start

Add a unique data-column identifier to each header. A data-type enables type-aware sorting.

<link rel="stylesheet" href="enhanced-bootstrap-table/enhancedTable.css">
<script src="enhanced-bootstrap-table/enhancedTable.js"></script>

<table class="table resizable-table" id="people">
  <thead><tr>
    <th data-column="name" data-type="text">Name</th>
    <th data-column="joined" data-type="date">Joined</th>
  </tr></thead>
  <tbody>...</tbody>
</table>

<script>
  const enhancer = new BootstrapTableEnhancer();
  enhancer.enhance('people');
</script>
For JSON population, include JSONforEnhancedTable.js and see the full module README for the data-populator API.

Supported data types

Use values such as text, whole-number, decimal, currency, date, time, true-false, phone-number, and email-address in data-type.
