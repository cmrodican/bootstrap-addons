bsColors

A broad palette of named CSS color helpers, exposed as text and background utility classes for quick styling.

Open bsColors.css ↗View on GitHub ↗

Preview

Text utilities use the .text-{color-name} naming pattern.

.text-light-coral.text-hot-pink.text-plum.text-pale-green.text-sky-blue

Quick start

Include the stylesheet after Bootstrap, then add a color class to an element.

<link rel="stylesheet" href="bsColors.css">

<p class="text-coral">Coral text</p>

The stylesheet includes text classes and background-color variants. Class names use CSS color names in lowercase, with spaces converted to hyphens.
