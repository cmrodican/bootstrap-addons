CSS Grid

Use responsive, CSS-only grid utilities alongside Bootstrap, or structure a whole page with semantic layout regions.

Read the guide ↗Browse source ↗

Two complementary stylesheets

css-grid.css provides grid utilities such as responsive column spans and start positions. semantic-grid.css provides a page-level template using header, navigation, main, sidebar, and footer areas.

12 columnsResponsiveCSS only

Utility grid quick start

Load the CSS Grid utilities, create a .grid container, and set spans on its children.

<link rel="stylesheet" href="css-grid/css-grid.css">

<div class="grid">
  <div class="g-col-12 g-col-md-8">Main content</div>
  <div class="g-col-12 g-col-md-4">Sidebar</div>
</div>

Set --bs-columns, --bs-rows, and --bs-gap on the grid container to customize its structure.

Semantic page layout

For a full-page structure, load semantic-grid.css and wrap semantic elements in .grid-container. The stylesheet maps those elements into named areas and stacks them on smaller screens.

<link rel="stylesheet" href="css-grid/semantic-grid.css">

<div class="grid-container">
  <header>Site title</header>
  <nav>Navigation</nav>
  <main>Page content</main>
  <aside>Sidebar</aside>
  <footer>Footer</footer>
</div>
