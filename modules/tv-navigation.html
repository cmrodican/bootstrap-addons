TV Navigation Framework

Add directional keyboard, gamepad, and remote-style focus navigation to interfaces built for TVs, kiosks, and large screens.

Try the test page ↗View the Netflix-style demo ↗

Navigation features

  • Directional movement between focusable elements.
  • Keyboard and gamepad support.
  • Focus management for modals and dynamic content.
  • Optional focus styles, help, status, and audio feedback.

Use the focusable selector option to match the framework to your UI. The default selector includes buttons, links, form controls, and elements marked with .tv-nav-focusable.

Quick start

Load the framework CSS and JavaScript. Creating an instance initializes the navigation behavior.

<link rel="stylesheet"
  href="tv-navigation-framework/tv-navigation-framework.css">

<button class="tv-nav-focusable">Play</button>
<a class="tv-nav-focusable" href="/browse">Browse</a>

<script src="tv-navigation-framework/tv-navigation-framework.js"></script>
<script>
  const tvNavigation = new TVNavigationFramework({
    enableAudio: false
  });
</script>
The framework starts automatically in its constructor; do not call init() again. Set enableAudio: false if your interface should not initialize optional audio feedback.
